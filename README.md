## Yams

Application de Yams pour téléphone (1 à 4 joueurs sur le même appareil) dans le dossier [`yams/`](yams/).
Ouvrez `yams/index.html` (ou l'adresse GitHub Pages `/yams/`), puis « Ajouter à l'écran d'accueil » pour l'installer ; elle fonctionne ensuite hors connexion.
